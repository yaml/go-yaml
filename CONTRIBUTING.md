# Contributing to go-yaml (v2 Branch)

**NOTICE:** The `v2` branch of `yaml/go-yaml` is in **Security-Only Maintenance Mode**.

## Scope of Contributions

We **do not** accept Pull Requests on this branch for:
* New features or API enhancements.
* General bug fixes or performance improvements.
* Backports of features, improvements, or non-security fixes from the `main` branch.

### Accepted Contributions
We only accept Pull Requests addressing **critical security vulnerabilities**.

### Where to Submit New Work
If you want to contribute new features, general bug fixes, or improvements, please direct your work to the [`main` branch](https://github.com/yaml/go-yaml/tree/main), which contains `v4`. PRs submitted here for anything other than verified security fixes will be closed without review.
